The staged media mod now has a desktop band and a pane. On the Desktop app's Code tab, the band shows the mark, a short headline, up to four thumbnails, a View button and a Hide button. View, or the new `/uploads-staged` command, opens a "Staged attachments" pane with a thumbnail grid, per-file detail, copy-markdown, remove, and a PR feed link. All surfaces now say "attachments" and leave the branch name out of the band.
