## Capture a screenshot <a class="anchor" data-pagefind-ignore href="#screenshot" aria-label="Link to this section">#</a>

`screenshot` renders a URL or a local `.html` file and hosts the image in one step:

```bash
uploads screenshot http://localhost:3000/settings --pr 123
```

Leave off `--pr` and it [stages on your branch](/docs/attach-pull-request-images#staging), the same
way `put` does.

It runs in the Chrome or Chromium you already have, so `localhost` works. No browser? Install
Chrome, or run `npx playwright install chromium`.

Common flags:

- `--dark` renders in dark mode.
- `--selector <css>` captures one element instead of the viewport.
- `--out <path>` also saves a local copy.

For dev-server options, like hiding overlays or waiting for the app to load, run
`uploads screenshot --help`.

</section>

<section id="redact">

## Redact secrets <a class="anchor" data-pagefind-ignore href="#redact" aria-label="Link to this section">#</a>

Hosted files are public. If the page shows an API key, a token, or someone's email, black it out
before capture with a CSS selector:

```bash
uploads screenshot http://localhost:3000/settings --redact '[data-testid=api-key]' --redact .email
```

Each match becomes a solid box, text and images included, and the layout doesn't shift. A selector
that matches nothing fails the capture instead of uploading the page unredacted.

</section>
