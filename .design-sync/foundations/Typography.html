Type scale

Sizes are roles, not numbers. Never hardcode a pixel value — pick the role that matches the job and the scale stays coherent when it changes. Nothing in this system renders below 12px.

The mono rule

Reach for --mono when the characters are something the reader transcribes or compares column-to-column. Never to make a word look technical. The terminal character of this system comes from Geist Pixel, the chevron motif, and the density.

Two escape hatches: ul-input--key puts a form field's value in mono, and --mono-optical scales inline code down one step so it sits on the baseline of the sans around it.

Leading, tracking, measure

Light text on a dark ground needs more air than the same face on white, so body sits at --leading-body (1.65) rather than the usual 1.5, and text sizes carry a hair of positive tracking to counter dark-mode bloom. Display sizes go negative to close optical gaps.

Prose is capped at --measure — 68 characters. Past roughly 75 the eye loses the start of the next line and reading slows; this paragraph is set at the cap so you can see where the limit falls. Cap the prose, not the column: code blocks, tables, and figures still get the full width they need.
